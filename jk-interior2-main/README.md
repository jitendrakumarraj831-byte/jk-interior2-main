# JK Interior - Premium Interior Design Website

A modern, optimized interior design website showcasing PVC wall paneling, false ceiling, and home decor services in Forbesganj, Bihar.

## 🚀 Features

- **Pinterest-Style Gallery**: Masonry layout with lightbox functionality
- **SEO Optimized**: Dynamic metadata, OpenGraph tags, structured data
- **Performance Optimized**: Next.js Image optimization, lazy loading, code splitting
- **100% Responsive**: Mobile-first design with cross-device compatibility
- **Professional UI**: Modern design with smooth animations and interactions

## 🛠️ Tech Stack

- **Framework**: Next.js 15 with App Router
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Components**: Radix UI
- **Analytics**: Vercel Analytics

## 📦 Deployment

### Vercel (Recommended)
1. Push code to GitHub repository
2. Connect repository to Vercel
3. Auto-deployment on push to main branch

### Manual Build
```bash
# Install dependencies
npm install

# Build for production
npm run build

# Start production server
npm start
```
